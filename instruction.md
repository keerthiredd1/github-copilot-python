# Copilot Instructions

General Guidelines

- Refactor legacy code into modular, reusable components.
- Follow Python best practices and PEP 8.
- Keep functions short and readable.
- Add docstrings to all public functions.
- Use type hints where appropriate.
- Avoid duplicated code.
- Handle errors gracefully.
- Preserve existing functionality while refactoring.

Project Goals

- Flask Sudoku application.
- Difficulty selector (Easy, Medium, Hard).
- Generate puzzles with exactly one unique solution.
- Locked prefilled cells.
- Hint button.
- Check button.
- Timer.
- Dark mode.
- Top 10 leaderboard using browser localStorage.
- Responsive layout.
- Mobile friendly.
- Clean CSS.
- Maintain accessibility.

Testing

- Use pytest.
- Never remove passing tests.
- Add tests for new features when possible.

Code Style

- Use descriptive variable names.
- Use comments only where necessary.
- Keep business logic separate from UI.
